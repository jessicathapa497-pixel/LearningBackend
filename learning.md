# User Register

## Normal User
  1. Fill up the form
  2. Click register button


## For Developer
  1. Destructure form data
  2. Check for validation
  3. Check for the unique email
  4. Hashing the password
  5. Generate token
  6. Store data
  7. Message via status code
    - 200 (sucess...)
    - 201 (created... new data)
    - 400 (normal error message)
    - 404 (..not found)
    - 500 (Internal Server error)
